背景：
当前已有测试覆盖：
- `classifyClosureStatus` 基础分类；
- `not_checked` 不等于 `no_change_closed`；
- `resource_failed` 优先级；
- pipeline report 中 `resource_failed` / `normal_closed` 的 closureStatus 输出；
- `no_change_closed` 不会在 blocking / FAILED / WARN / plan violations 下出现。

仍建议补齐：
- 更直接的 no-change 样例；
- report consumer 层能读取 `no_change_closed`；
- 缺失检查 `not_checked` 的报告或分类断言；
- 避免只用快照掩盖逻辑。
