- 重写结尾最后3-5段

- 当前4002字太长，压缩到1500-2500字
- 删除重复说明、冗长环境描写、重复心理活动
- 不删除关键剧情节点

5. 禁止：
- 不新增大设定
- 不改变后续状态
- 不改变主角和云岚的核心关系方向
- 不整章完全换剧情
- 不输出解释，只输出修复后的完整章节正文

结构必须满足：
Hook → Pressure → Attempt → Twist → Payoff → Pull
