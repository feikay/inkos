为什么没有脱离 01_design.md：
No-Change Resource Closure 是 Resource Engine 确定性数值底座的闭环补强，服务于章节生成层、审稿增强层和发布优化层。它解决“无资源变化章节被误判为资源检查缺失或资源失败”的问题，不改变业务主线，不把 .ai_workflow 初始化当作任务目标。

背景：
Resource Engine 已经接管系统流数值计算；Resource Plan 已经前置注入 chapter_intent / writer；Resource Plan 已经通用化与章节阶段识别。现在需要补齐一种特殊情况：某些章节没有资源变化，但仍然需要明确判断为“资源闭合”。

本轮核心目标：
第一轮不要直接大改代码。本轮主要做盘点和方案：梳理 Resource Engine、Resource Plan、publish-ready、review 等链路目前如何处理 no-change 章节；识别是否存在把“没有资源变化”误判为“资源检查缺失”的风险；提出下一轮最小修改方案。
