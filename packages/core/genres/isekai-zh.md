## 题材禁忌

- "新手村综合症"——50页打小怪刷经验，正事迟迟不开
- 异世界就是地球换个皮——文化、制度、价值观完全雷同
- 主角用俯视态度对待异世界文化且没有叙事后果
- 文化误解没有真实代价——水土不服必须有代价
- "文化学习"阶段节奏太慢——用行动渗透规则，不用课堂讲解
- 原世界第3章后彻底消失——两个世界的反差是穿越文的核心引擎
- 穿越方式毫无个性——穿越事件本身要有戏剧性

## 穿越规则

- 穿越事件（召唤、转世、传送门）必须有辨识度和记忆点
- 简短的原世界锚定：主角穿越前是什么人？带走了什么技能、知识、关系？
- 抵达场景：真实的不适感——感官过载、语言障碍、身体不适
- 第一个引路人通过互动介绍世界基本规则，不是念设定稿
- 前3章内读者必须理解异世界的基本运作方式
- 原世界知识既是优势也是危险的盲区
- 异世界必须有真实感：连贯的地理、政治、文化、经济——不是游戏大厅

## 语言铁律

- 主角内心独白体现"异乡人"的陌生感，但不碎碎念
- ✗"这个世界的规则完全不同！" → ✓"没人看路牌，连路牌都没有"
- 异世界角色说话有自己的语感节奏，不和主角一个腔调
- 文化差异用行动展现，不用主角内心独白解释

## 叙事指导

以文化冲突和知识差驱动剧情。
主角的原世界知识在异世界产生的化学反应是核心爽点。
但原世界知识不是万能的——在不同物理规则/文化逻辑下可能适得其反。

穿越事件 → 简短原世界锚定 → 抵达和不适 → 第一个引路人 → 第一个具体目标
早期：文化水土不服驱动喜剧和戏剧（每2-3章一次）
中期：主角身份从"外来者"向"参与者"转变——必须追踪这个弧线
后期：两个世界的联系可能重新浮出水面

异世界的权力结构必须有内在逻辑，不能全是为主角服务的NPC。
主角的每一个文化误判都必须有后果，不能靠运气兜底。
