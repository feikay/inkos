# Writer 模板问题报告

项目：《葬渊魔经》
阶段：番茄发布前二轮精修

## 判断

本轮发现的模板句并非单章偶发，更像来自 writer 的章节推进与章节尾收束模板。高频模式集中在早期暗河探索段与中后期宗门/青铜殿过渡段。

## 高频句式与频率

| 句式/模式 | 正式章节命中情况 | 说明 |
| --- | ---: | --- |
| “真正的危险/考验/挑战/战斗/狩猎才刚刚开始” | 约 17 处 | 用抽象预告替代具体悬念，尤其常出现在战斗后、章节末。 |
| “继续深入/继续前行/向深处进发” | 约 20+ 处 | 作为默认位移句，缺少地形、代价、线索触发。 |
| “隐藏着更多秘密/更多秘密/真正的真相” | 约 10+ 处 | 线索发现后用同一组抽象词收束，信息密度低。 |
| “只是冰山一角” | 约 8 处 | 典型总结式悬念，容易显得作者旁白在替剧情发力。 |
| “战斗 → 击败 → 灵气结晶/药材 → 玉牌/卷轴” | 0007-0018 多章连续 | 事件顺序高度相似，削弱每章记忆点。 |
| “紧张/压抑/危险/神秘”泛化情绪词 | 全文仍有自然残留 | 这些词本身可用，但不能承担关键气氛塑造。 |

## 可能来自 writer 的模板

1. 战斗收束模板

原模式：

```text
经过一番激战，敌人倒下。
主角获得资源/线索。
但这只是暂时胜利，真正的危险/考验才刚刚开始。
```

建议改为：

```text
战斗结束后，必须出现一个可被读者看见/听见/触到的后果：
- 尸体异常变化
- 物件反应
- 地形改变
- 伤势代价加重
- 第三方痕迹出现
禁止使用“真正的危险/考验/挑战才刚刚开始”作为章节收束。
```

2. 探索推进模板

原模式：

```text
他们继续深入洞穴/暗河尽头。
前方道路充满未知和危险。
```

建议改为：

```text
位移必须由具体触发物驱动：
- 水痕、脚印、血迹、药香、符文亮灭
- 玉牌发热、卷轴吸灵、石门错位
- 地面下沉、雾墙驱赶、铃声/低语误导
禁止单独使用“继续深入”推进剧情。
```

3. 线索总结模板

原模式：

```text
这里隐藏着更多秘密。
真正的真相还需要他们一步步揭开。
```

建议改为：

```text
发现线索后必须给出一个具体未解点：
- 石碑背面血迹未干
- 卷轴背面多出半行字
- 玉牌凹槽对应第二枚缺口
- 骸骨裂纹与主角伤口一致
禁止用“更多秘密/真正真相/冰山一角”概括。
```

4. 情绪词替换规则

建议 writer prompt 增加：

```text
不要直接写“紧张、压抑、危险、神秘”来制造气氛。
优先写生理反馈、环境反应、动作变化：
- 喉咙发干、指节发白、呼吸被压低
- 水声停住、花瓣收拢、符文熄灭
- 脚步放轻、武器提前出鞘、对话缩短
```

## 推荐写入 writer prompt 的约束

```text
每章结尾必须用具体画面或动作制造悬念，不允许使用抽象预告句。
禁用句：
- 真正的危险才刚刚开始
- 真正的考验才刚刚开始
- 真正的挑战才刚刚开始
- 他们继续深入
- 隐藏着更多秘密
- 只是冰山一角
- 真正的真相

当剧情需要推进地点时，不写“继续深入/继续前行”，改写为“被某个具体线索牵引而移动”。

连续三章内不得重复“战斗 → 击杀 → 掉落 → 玉牌/卷轴”的流程。
必须从以下触发顺序中轮换：
- 异象先行
- 资源先行
- 陷阱先行
- 人物先行
- 代价先行

战斗胜利后必须写代价或异常，不允许只写收获。
```
