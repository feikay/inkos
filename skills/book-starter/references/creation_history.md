# 新书创建历史记录

记录通过 `book-starter` 技能创建的书籍历史，用于分析和改进推荐质量。

---

## 记录格式

每次创建书籍时，按以下格式记录：

```markdown
## YYYY-MM-DD HH:MM

**用户信息**：
- 原始需求：[用户说的原始需求]
- 解析题材：[解析出的题材ID]

**候选方案**：
1. 《书名1》- [主题方向摘要]
2. 《书名2》- [主题方向摘要]
3. 《书名3》- [主题方向摘要]

**用户选择**：方案 X

**创建结果**：
- 书名：《最终书名》
- 书籍ID：xxx
- 匹配度：[高/中/低] (XX%)

**用户反馈**：
- 是否通过：[是/否/重新生成X次后通过]
- 反馈意见：[用户的具体反馈]

**重试次数**：X 次

---

```
